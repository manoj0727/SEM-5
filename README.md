# SEM-5 ECE Study Materials

This repository contains study materials, lecture notes, practicals, and previous year question papers for Semester 5 (ECE).

## Subjects Covered

| Folder | Subject | Description |
|--------|---------|-------------|
| `FUZZY/` | Fuzzy Logic & Neural Networks | Lectures on Fuzzy Logic (FL-I to FL-V) and Neural Networks (NN-1 to NN-7) |
| `I&E/` | Innovation & Entrepreneurship | Unit-wise notes and TBI types |
| `IPCV/` | Image Processing & Computer Vision | Theory notes covering image fundamentals, enhancement, restoration, morphological processing, and segmentation |
| `IPCV_P/` | IPCV Practicals | MATLAB/code files for image processing operations (filtering, morphology, transformations, etc.) |
| `Wirelesss/` | Wireless Communication | Unit-wise notes, reference books, OFDM, propagation models, traffic calculation, and practicals |
| `ccbdi/` | Cloud Computing & Big Data Infrastructure | Lecture PDFs, previous year question papers (2018-2025), and cloud security topics |
| `physics/` | Nanoscale Device Engineering (NDE) | Nanoscience applications, display devices, memory devices, SPICE models, and SiGe layouts |
| `sih/` | Smart India Hackathon | SIH 2025 idea presentation files |

## Content Organization


## Notes

- **Syllabus**: The complete semester syllabus is available in `sem-5_ECE.pdf`
- **Previous Year Papers**: Available in `ccbdi/` folder (2018-2025)
- **Practicals**: IPCV practicals are in `IPCV_P/`, Wireless practicals are in `Wirelesss/wc_prac/`
- **Reference Books**: Wireless Communication reference book by Theodore Rappaport (with solutions) is included

## Usage

1. Navigate to the subject folder you need
2. Open the relevant PDF/notes for theory
3. For practicals, check the respective practical folders (`IPCV_P/`, `wc_prac/`)
